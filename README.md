# pdf-tables-to-csv

Pull every table out of a PDF into a clean CSV or one Excel workbook, with one command.

Made for the PDFs people actually get sent: **bank statements, supplier price lists, invoices and reports** whose tables run across many pages with the header repeated on each page.

```
python pdf_tables_to_csv.py statement.pdf            # -> statement.csv
python pdf_tables_to_csv.py statement.pdf --xlsx     # -> statement.xlsx
```

## What it does that copy-and-paste doesn't

- **Joins tables split across pages.** The header that repeats on every page is kept once; every row stays in order.
- **Cleans cells.** Text that wrapped onto two lines inside a cell comes out as one line; stray spaces go.
- **Real numbers on request.** `--numbers` turns `£1,234.50` into `1234.5`, `(12.00)` into `-12`, and `50.00 DR` into `-50`, so you can add them up in Excel. Dates and references are left alone.
- **Excel-ready.** CSVs are written as UTF-8 with a BOM so `£` shows correctly in Excel. `--xlsx` gives a workbook with a bold, frozen header row and sized columns.
- **Private.** Runs on your own computer. Nothing is uploaded anywhere.

## Install

```
pip install -r requirements.txt
```

Python 3.9 or newer. Dependencies: [pdfplumber](https://github.com/jsvine/pdfplumber) and openpyxl.

## Usage

```
python pdf_tables_to_csv.py report.pdf --separate          # one CSV per table
python pdf_tables_to_csv.py report.pdf --pages 2-5         # only some pages
python pdf_tables_to_csv.py report.pdf --xlsx --numbers    # one workbook, real numbers
python pdf_tables_to_csv.py report.pdf --text              # tables with no ruled lines
python pdf_tables_to_csv.py report.pdf -o out/march        # choose the output name
```

As a library:

```python
import pdf_tables_to_csv as p

tables = p.extract_tables("statement.pdf")      # [{'page': 1, 'rows': [...]}, ...]
rows = p.merge_tables(tables)                    # one table, header once
rows = p.convert_rows(rows, numbers=True)
p.write_csv(rows, Path("statement.csv"))
```

Try it on the sample in `examples/` (`sample-statement.pdf`, made-up data): it turns a 2-page, 60-row statement into the 61-line `sample-statement.csv` next to it.

## When it won't work

- **Scanned PDFs** (a photo of paper) have no text inside, so there is nothing to extract. They need OCR first.
- **Tables without lines** sometimes split columns in the wrong place. Try `--text`, then check the result.
- **Merged cells and multi-row headers** come out as they are in the PDF; you may need to tidy the header row by hand.
